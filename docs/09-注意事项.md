# 09 · 注意事项

> 使用前值得先看一遍的几条。安装步骤见 [`README`](../README.md) 的 [📥 两份配置](../README.md#-两份配置)。

---

| 项目 | 说明 |
|:----:|:-----|
| 🧩 **`lazy` 的 `Proxy` 必须填** | 它没有 `Airport-*` 订阅槽位，`Proxy` 空着就**所有走代理的流量都不通**（其余版本填订阅即可） |
| 🔄 **规则集自动更新** | `routing_v2.4` 起 21 条 `rule_set` 均带 `update_interval: 86400`（按天刷新）。`routing_v2.3` 及更早版本**缺此字段**，规则集可能长期停在首次下载的版本 —— 上游新收录的域名会一直命不中 |
| 🧪 **全部本地完成** | 本仓库**刻意不挂 CI / 任何自动化**（理由见 [`skill/README.md`](../skill/README.md)）—— 改完 profile 本地跑一遍 [`docs/08`](08-审计读数.md) 里那批脚本即可 |
